# Teledok API

## Описание

Backend-сервис для управления клиентами (физическими лицами и юридическими лицами) и их учредителями.

Проект реализован с акцентом на:
- DDD-lite подход
- разделение слоёв
- работу с EF Core и PostgreSQL
- валидацию доменной модели

---

## Технологии

- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- Docker / Docker Compose
- C#

---

## Архитектура решения

Проект разделён на слои:

- **Teledok.Api** — HTTP API (контроллеры)
- **Teledok.Application** — бизнес-логика (сервисы, сценарии)
- **Teledok.Domain** — доменная модель и бизнес-правила
- **Teledok.Infrastructure** — доступ к данным (EF Core, репозитории)
- **Teledok.Contracts** — DTO, запросы и ответы

---

## Доменная модель

Основная сущность:

- `Person` — агрегатный корень (Клиент)

Подчинённая сущность:

- `Founder` — учредитель (часть юридического лица)

### Бизнес-правила:

- Юридическое лицо может иметь нескольких учредителей
- Индивидуальный предприниматель не может иметь учредителей
- ИНН валидируется в зависимости от типа клиента
- Валидация выполняется в доменной модели

## API
## Person (клиенты)

### Получение

- **GET** `/api/person`  
  Получить всех клиентов

- **GET** `/api/person/{id}`  
  Получить клиента по ID

- **GET** `/api/person/inn/{inn}`  
  Получить клиента по ИНН

- **GET** `/api/person/legal-entity/inn/{inn}`  
  Получить юридическое лицо вместе с учредителями

---

### Создание

- **POST** `/api/person`  
  Создать индивидуального предпринимателя

- **POST** `/api/person/legal-entity`  
  Создать юридическое лицо с учредителями

---

### Обновление

- **PUT** `/api/person`  
  Обновить данные клиента

---

### Удаление

- **DELETE** `/api/person/{id}`  
  Удалить клиента

---

## Founders (учредители)

- **POST** `/api/person/founders`  
  Добавить учредителя юридическому лицу

- **PUT** `/api/person/founders`  
  Обновить данные учредителя

- **DELETE** `/api/person/founders/{personId}/{founderInn}`  
  Удалить учредителя из юридического лица
